# CodeBud: product notes

The original product brief: vision, personas, user stories and design guidelines.

## Product vision

**FOR** preschool children aged 4 to 7,
**WHO** are just beginning to explore thinking in sequences and logic,
**THE** CodeBud App is an educational app
**THAT** helps develop programming and algorithmic thinking skills through interactive, visual puzzles.
**UNLIKE** traditional text-based tools,
**OUR PRODUCT** provides a completely text-free, drag-and-drop interface with friendly animations and sounds, making coding concepts like sequencing, loops, and conditionals intuitive and fun for early learners.

## User personas

1. **Ella (age 5):** loves bright visuals and reacts to fun sounds. She learns through repetition and needs simple instructions.
2. **Liam (age 6):** curious and loves solving puzzles. He can understand logical relationships with visual cues.
3. **Sophia (age 4):** new to digital interfaces. She needs an intuitive design to avoid frustration and encourage interaction.

## Core features

1. **Drag-and-drop command blocks:** visual icons instead of text. Children drag blocks onto a sequence strip to form their "code".
2. **Puzzle-based levels:** guide CodeBud to the star. Complexity grows gradually: straight paths, then turns, then obstacles, then logic.
3. **Loops:** a "repeat" block. Children drop commands inside it and set the number of repeats visually.
4. **If-then logic:** e.g. *if there's a rock to the right, go down*, shown with icons, not words.
5. **Feedback and rewards:** sounds, animations, and 1–3 stars based on how short the program is.

## User stories

**Puzzle navigation:** *as a child, I want to guide CodeBud through puzzles using drag-and-drop blocks, so that I can reach the goal and feel a sense of achievement.*
- A grid-based level appears. CodeBud follows the command sequence. Reaching the goal plays an animation.

**Looping movement:** *as a player, I want to use loops to repeat actions, so that I can solve puzzles more efficiently.*
- I can drag a loop block into the sequence, put commands inside it, and choose how many times it repeats.

**Obstacle handling with conditionals:** *as a child, I want to make CodeBud avoid obstacles using if-then blocks, so that I can solve more complex levels.*
- An if block is available. It checks the neighbouring cell and runs its action when the condition matches.

**Feedback and stars:** *as a young learner, I want to receive stars and hear sounds when I solve a puzzle, so that I feel rewarded and want to keep playing.*
- Finishing a level shows stars based on efficiency, with cheerful animations and sounds.

## Design guidelines

- **No text for the child:** instructions and gameplay use images, animation and sound.
- **Touch-friendly:** large buttons and drop areas to suit young children's motor skills.
- **Progressive difficulty:** concepts are introduced gradually. Levels unlock in order.
- **Safe and encouraging:** no failure penalties. A missed star brings a hint and another try.

## Future ideas

- More characters and themes
- A parent dashboard with progress over time
- More languages for the grown-up screens
